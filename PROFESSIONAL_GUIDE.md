## 📞 TROUBLESHOOTING

### **Problem 1: Charts ko'rinmayapti**
```
✅ Solution:
1. Page refresh qiling (F5)
2. Browser cache tozalang
3. Internet connection tekshiring
4. JavaScript enabled bo'lishini tekshiring
```

### **Problem 2: Filterlar ish qilmayapti**
```
✅ Solution:
1. Sahifani reload qiling
2. Barcha filterlarni reset qiling
3. Selection-ni qayta qiling
4. Browser devtools-ni oching (F12)
```

### **Problem 3: Export ish qilmayapti**
```
✅ Solution:
1. Pop-up blocker-ni o'chiring
2. Download folder-ni tekshiring
3. Browser permissions-ni tekshiring
4. CSV o'rniga Print to PDF ishlatib ko'ring
```

### **Problem 4: Mobile-da yuzaki masalalar**
```
✅ Solution:
1. Brauzer refresh qiling
2. Orientation o'zgartiring
3. Zoom level o'chiring
4. Mobile brauzer update qiling
```
